Verify on Linux

Save the ZIP, checksum, signature, public key and allowed-signers file in one folder. Check the key fingerprint against your trusted copy first:

ssh-keygen -lf release-signing-key.pub

Build the signer policy from the public key whose fingerprint you just verified (do not trust a separate downloaded policy without checking it):

printf 'releases@xbtpulse.tech namespaces="releases@xbtpulse.tech" %s\n' "$(cat release-signing-key.pub)" > allowed_signers

For the DATUM collector, verify the checksum signature:

ssh-keygen -Y verify -f allowed_signers \
  -I releases@xbtpulse.tech -n releases@xbtpulse.tech \
  -s SHA256SUMS.txt.sig < SHA256SUMS.txt

Only after signature verification succeeds, verify the downloaded archive:

sha256sum -c SHA256SUMS.txt

For the adapter kit, substitute ADAPTER-SHA256SUMS.txt and ADAPTER-SHA256SUMS.txt.sig. Stop on any failure.

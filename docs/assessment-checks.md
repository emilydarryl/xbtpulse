# Assessment assistant

In an application's scorecard, set the observation start and end dates and select **Run assessment checks**. Dates are UTC, with the end date inclusive up to the current time. The API accepts at most 35 days and caches repeat requests for one minute. Calls require the existing admin login, Origin and CSRF checks.

The assistant measures complete accepted telemetry intervals per provider: time coverage, uncovered ranges, largest gap, recent positive work, overlap, inconsistent work/outcome totals and reported found/expected blocks. Providers are never combined into a network coverage estimate. Existing reports only had eight-day retention; retention now extends to 35 days. A stored deployment baseline prevents older missing history being treated as proven downtime or earning a numerical coverage suggestion.

A conditional telemetry percentage is offered only for one active reporting provider with complete retention, positive work, consistent non-overlapping intervals. It is a time-coverage result. The reviewer must independently check full scope, representativeness, counter units, resets and block reconciliation before accepting it as a rubric result. Other criteria remain unassessed; protocol names, website keywords and credential possession are not independent evidence of template control or ownership.

Up to three submitted/published website sources are checked in parallel. HTTPS only, no credentials/query strings/nonstandard ports; IPv4 DNS answers must be public and the connection is pinned to a validated answer. Every redirect is separately validated, with two redirects maximum. DNS/request deadlines, a 350 KB response limit and content-type checks bound retrieval. JavaScript is not executed. Failures and pages with no useful excerpts require manual source review. Retrieved text is untrusted and never executed. Dates, final URL, content hash and up to six short excerpts are retained privately with the latest result. Hash changes may reflect dynamic navigation, not a fee change. No external messages are sent.

Findings are separate from scorecard drafts. Add individual notes to the unsaved form, review source claims, then use Save draft & preview. A confirmed conditional score can replace the corresponding form value, but no save or publication occurs automatically. Existing text is appended to within the evidence limit; longer notes require editing. Observation dates must still match the check before accepting a suggestion. The assistant also generates an editable follow-up message for manual copying. Publication still uses the original reviewer confirmation and evidence gates.
